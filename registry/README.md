# Source registry

`registry/sources.csv` contains the active non-language source families and high-value datasets. `data.gouv.ci` is intentionally represented both by its catalog and by selected high-value datasets; `scripts/discover_data_gouv_ci.py` expands the official catalog dynamically so the project is not frozen to a hand-maintained list.

Rights tiers control where downloaded material may be stored or republished. See `docs/RIGHTS_AND_ACCESS.md`.
